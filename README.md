# PU Space
A simple room booking website for President University students. Users can browse available rooms, book a room, check the booking schedule, and contact the administrator.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with a short intro and how the system works |
| Rooms | `rooms.html` | List of rooms with capacity and availability status |
| Booking | `booking.html` | Form to book a room |
| Schedule | `schedule.html` | Table of room bookings and their status |
| Contact | `contact.html` | Booking process, booking rules, and administrator contact |
